# design intelligence（ui-ux-pro-max 三维度）

上游：https://github.com/nextlevelbuilder/ui-ux-pro-max-skill（`.claude/skills/ui-ux-pro-max/SKILL.md`）
作者：@nextlevelbuilder · 许可以原仓库为准
用途：需要"视觉层级 / 色彩心理 / 交互模式"三个维度的具体判断时读。

## 何时读

- 页面元素都齐了但读不出主次；
- 选色犹豫，或配色显得廉价；
- 交互方式不确定（弹窗还是抽屉、即时还是确认）。

## 维度一：视觉层级

四个手段，按效力排序：**尺寸 > 对比 > 位置 > 装饰**。

- 一屏只能有一个主视觉；出现两个同权重元素，先合并或降级一个。
- 层级靠"结构差"（大小、空白、满色块），不靠加边框、加阴影、加图标。
- 标题层级最多 5 级且步进明显（如 48 / 32 / 24 / 18 / 16），不要 24 与 20 并存。
- 留白是层级的一部分：元素之间的空白差，比元素本身的样式更能说明谁属于谁。

## 维度二：色彩心理

- 先定行业色彩预期，再决定"顺从还是偏离"；偏离要能说出理由（否则就是随机）。
- 60-30-10：主色 60%（底）、次色 30%（表面与文字）、强调色 ≤10%；强调色只出现在主操作与一处呼应。
- 语义色固定：成功绿、警告黄、错误红、信息蓝；不要用品牌强调色承担错误语义。
- 深色主题不是反相：用近黑 + 提亮表面分层层级，强调色饱和度要降。
- 纯灰最容易显廉价：给中性色带一点色相（冷灰偏蓝、暖灰偏黄），但全站只用一个倾向。

## 维度三：交互模式

- 直接操作优先（拖、滑、就地编辑），但必须提供点按与键盘的等价路径。
- 渐进披露：先给主路径，进阶选项收进"更多"，不要让首屏承担所有配置。
- 即时反馈：所有异步动作都要有进行中状态；超过 300ms 用骨架屏。
- 可逆优先于确认：能撤销的就不弹确认框；破坏性且不可逆才确认。
- 选择控件按选项数量决定：2–7 用分段/单选，8+ 用下拉或搜索式。

## 设计系统选择

| 场景 | 优先 |
| --- | --- |
| 企业内部、Office 生态 | Fluent |
| 跨平台、Android 优先 | Material 3 |
| 金融/企业后台 | Carbon / Polaris |
| React 快速搭建 | shadcn/ui + Tailwind |
| 单页/活动/作品集 | 原生 CSS |
