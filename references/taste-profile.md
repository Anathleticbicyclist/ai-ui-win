# 品味档案与参考板（tastemaker）

上游：https://github.com/codeswithroh/tastemaker（`skills/tastemaker/SKILL.md`，示例档案在 `.tastemaker/`）
作者：@codeswithroh · 许可以原仓库为准
用途：把"我喜欢这种感觉"变成可复用的约束文件，让后续每次产出都落在同一个世界里。

## 何时读

- 用户给不出风格词，但能给出"我喜欢的几个网站/图"；
- 同一产品要做多个页面，需要保证风格不漂移；
- 团队需要把审美沉淀成文档。

## 三个档案文件（tastemaker 的做法，本技能沿用）

| 文件 | 内容 | 作用 |
| --- | --- | --- |
| `reference-board.md` | 3–5 张参考图 + 每张"为什么它对"（字型、底色、强调色位置、版式骨架、图像处理） | 方向的证据 |
| `style-lock.md` | 锁定的 token：ground / ink / accent / type / radius / spacing / motion | 每次生成前必读 |
| `decisions.log` | 每次决定改了什么、为什么 | 避免来回反复 |

## 四步流程

1. **collect**：收 3–5 张真实参考（截图即可），不要用"高级""简约"这类形容词代替。
2. **extract**：逐张写 3 行——它的底色与明度关系 / 它的字型对比（展示字号是正文的几倍）/ 它的强调色只出现在哪里。
3. **lock**：把抽取结果写成 6–10 行 style-lock（就是本技能的 token 计划），此后所有页面只允许在这套值内取。
4. **generate & compare**：产出后与参考板逐张对照，问"像不像同一个世界"，不像就改 token 而不是加装饰。

## 三条纪律

- 参考的是**决策**，不是像素：不复制布局、不复制 logo、不搬版权图片与文案。
- 参考板超过 5 张就失效——那会变成"什么都想要"。
- style-lock 一次只锁一套；要换世界就整份替换，不在旧锁上打补丁。

## 与本研究的关系

`explore-variants.md` 讲"怎么找到方向"，本文件讲"找到之后怎么固定住"。
两者合起来就是：先发散（2–3 个结构变体）→ 收敛（1 个）→ 锁死（style-lock）→ 后续页面复用。
