# surface 模式与 craft floor（impeccable）

上游：https://github.com/pbakaus/impeccable（`.claude/skills/impeccable/`，含 `SKILL.md` 与 `reference/craft-floor.md`）
作者：Paul Bakaus · 许可：Apache 2.0
用途：判断"这个界面该按什么标准做"，以及一条任何人都绕不过的质量地板。

## 何时读

- 同一产品里不同页面标准打架（官网很炸，工具页很土）；
- 需要判断"这里该克制还是该表现力"；
- 交付前要一条最低合格线。

## 四种 surface 模式

| 模式 | 访客的成功是什么 | 设计该优先 | 典型 |
| --- | --- | --- | --- |
| **Persuade** | 决定并行动 | 注意力与说服力，设计即产品；用真实影像 | 落地页、营销页、定价页 |
| **Operate** | 完成一个任务 | 可扫读、一致、原生预期、真实使用场景 | 后台、编辑器、设置、工具 |
| **Read** | 理解一件事 | 为理解而结构，再让阅读本身值得停留 | 文档、文章、帮助中心、更新日志 |
| **Experience** | 沉浸在作品里 | 作品先行，界面后退 | 作品集、画廊、展示页 |

关键规则：**按页面判模式，不按产品判**。工具的落地页是 Persuade，工具自己是 Operate，
时装屋的文档是 Read。同一站点可以同时存在四种模式。

对应到野心：
- Persuade / Experience → 全力表达，必须有观点；
- Operate / Read → 野心表现为**精度与克制**，用户已知的模式在这里是资产，不是平庸。

## craft floor（质量地板）

**Verify（逐项看渲染结果，不看代码）**

- **对比度**：正文与 placeholder ≥4.5:1，大字 ≥3:1；彩色表面上的次级文字从该色相派生，不要用灰色硬压。
- **层次**：阴影必须有偏移与柔和模糊；零偏移彩色光晕是装饰。
- **间距**：组内紧、组间松；标题上方的空间大于下方；读实际计算值，不凭肉眼。
- **字型**：正文 65–75ch，展示字号上限 6rem，字距下限 −0.04em，标题 balanced，层级与字重要有明显台阶。
- **动效**：只做一个有编排的时刻，不要散点特效，也不要每节都用同一种入场；从"已经可见"的状态用指数 ease-out 收尾。
- **状态**：hover / disabled / loading / error / empty 必须有，加上真实内容、可用控件、响应式构图、键盘焦点。
- **浏览器表面**：文字选区、光标、滚动条、焦点环、下划线偏移——这些你没画的部分也在承载设计。
- **文案**：用产品自己的语言；控件写动作，错误写问题与恢复方式。
- **覆盖**：brief 里每一条要求都在页面上、且能在几秒内被找到。

**Refuse（见到就算不合格）**

- 用"同尺寸卡片 + 图标 + 标题 + 一段字"当页面结构；卡片是最偷懒的容器，**嵌套卡片一定错**。
- hero-metric 模板：大数字 + 小标签 + 支撑统计 + 强调色。
- 每块都加阴影、每个区块都居中、重复"左文右图"行。
- 标题其实只是加粗正文（展示字号至少是正文的 2.5 倍）。
- `#000` 压 `#fff`（用近黑 + 暖白）。

## 设计词汇（沟通时用这些词，不用"高级感"）

层级（hierarchy）、节奏（rhythm）、可供性（affordance）、渐进披露（progressive disclosure）、
光学对齐（optical alignment）、密度（density）、留白（negative space）、签名元素（signature）、
反参考（anti-reference）、克制（restraint）。
